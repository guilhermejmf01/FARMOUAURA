# Turmas Aura — App de resultados por turma

App para lançar alunos por turma (aprovado / recuperação) e exibir um a um
com animações: aprovado "farmou aura" ✨, recuperação "aura negativa" 💀.
Inclui exportar/importar backup em JSON para levar os dados entre computadores.

## Como rodar

```bash
npm install
npm run dev
```

Abra http://localhost:8080 (ou a porta que o terminal mostrar).

## Testes

```bash
npm test
```
